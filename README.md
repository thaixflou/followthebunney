# Follow the Bunny (Glow Up v2)

A free, open source audit of where revenue leaks in your commercial flow. Answer a few questions for your profile and get a result in three horizons: **Today** (things you can do yourself), **This quarter** and **2-3 years**.

Work in progress. Nothing is stored and no AI is used: the audit runs in your browser and the same answers always give the same score.

Built by [Thais](https://revenuebythais.com).

## Run it

```
npm install
npm run dev
```
