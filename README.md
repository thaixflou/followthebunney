# Follow the Bunny (Glow Up v2)

A one-page offer for founders and owners whose business works but relies on referrals: a calculator that shows what the gap is worth, and a 4-week outbound sprint. English and Portuguese.

Work in progress. Nothing is stored and no AI is used: the calculator is plain arithmetic in your browser on the numbers you type.

Built by [Thais](https://revenuebythais.com).

## Run it

```
npm install
npm run dev
```
